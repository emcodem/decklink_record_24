================================================================================
FFRecord Monitoring Tools - Quick Reference
================================================================================

Scripts are in debugging\ within this project.
Bat wrappers are in C:\dev\cmd_recorder\scripts\tools\

WHEN TO USE EACH TOOL:

+- Device Locked? -----------------------------------------------------------------+
| Problem: Other app is using the device                                           |
| Tool: venv\Scripts\python.exe debugging\check_decklink_availability.py           |
|    or: C:\dev\cmd_recorder\scripts\tools\check_devices.bat                       |
| Time: 10 seconds                                                                 |
| Output: [AVAILABLE] or [IN USE]                                                  |
+----------------------------------------------------------------------------------+

+- No Video Signal? ---------------------------------------------------------------+
| Problem: Cable not connected, source off, wrong format                           |
| Tool: C:\dev\cmd_recorder\scripts\tools\detect_signal.bat 1  (1=CH02, 0=CH01)   |
| Time: 15 seconds                                                                 |
| Output: SIGNAL DETECTED or NO SIGNAL                                             |
+----------------------------------------------------------------------------------+

+- 0 FPS Persisting? --------------------------------------------------------------+
| Problem: Capturing, but getting 0 frames                                         |
| Tool: C:\dev\cmd_recorder\scripts\tools\monitor_capture_health.bat               |
| Time: Continuous (alerts after 30s of 0 fps)                                     |
| Output: Real-time alerts with causes and fixes                                   |
+----------------------------------------------------------------------------------+

+- Everything Wrong? --------------------------------------------------------------+
| Problem: Don't know where to start                                               |
| Tool: C:\dev\cmd_recorder\scripts\tools\quick_troubleshoot.bat                   |
| Time: 3 minutes (runs all checks in order)                                       |
| Output: Step-by-step diagnosis with recommended fixes                            |
+----------------------------------------------------------------------------------+

================================================================================
TYPICAL TROUBLESHOOTING FLOW:
================================================================================

1. Device shows 0 fps in logs?
   |
2. Run: C:\dev\cmd_recorder\scripts\tools\quick_troubleshoot.bat
   (Runs all diagnostics automatically)
   |
3. Check output:
   * Device [AVAILABLE]? -> Go to 4
   * Device [IN USE]?    -> Close other apps, re-run quick_troubleshoot.bat
   |
4. Signal detected?
   * SIGNAL DETECTED -> Check format matches YAML, restart recorder
   * NO SIGNAL       -> Check cable, verify source is on, try reconnecting
   |
5. Still 0 fps?
   * Run: C:\dev\cmd_recorder\scripts\tools\monitor_capture_health.bat
   * Keep it running while recorder runs
   * Wait for alert (after 30s of 0 fps)
   * Follow alert instructions

================================================================================
COMMON ISSUES & SOLUTIONS:
================================================================================

ISSUE: Device shows [IN USE]
  FIX: Close these applications:
    - Blackmagic Desktop Video Control Panel
    - DaVinci Resolve
    - Media Express
    - OBS Studio
    - Any other ffrecord instances
  VERIFY: Re-run check_devices.bat

ISSUE: Signal detection shows NO SIGNAL
  FIX: Check in this order:
    1. Is SDI/HDMI cable plugged into device input port? (not output)
    2. Is video source powered on?
    3. Is video source actively outputting? (can you see it on source monitor?)
    4. Try disconnecting/reconnecting cable
    5. Try different cable
    6. Try different video source

ISSUE: Signal detected but format doesn't match config
  Example:
    Config: expected_format: "1080i50"
    Signal: SIGNAL DETECTED: 1080p60  <- MISMATCH!
  FIX: Edit C:\dev\cmd_recorder\ffrecord_configs\ch02.yaml
       Change: expected_format: "1080p60"
       Restart recorder

ISSUE: Device available, signal detected, but still 0 fps
  FIX: Run monitor_capture_health.bat to watch logs in real-time
       It will alert with specific cause after 30 seconds of 0 fps

ISSUE: Monitor shows "Device initialized but not capturing"
  This means:
    * Device opened successfully
    * But no frames arriving
  Likely causes (in order):
    1. No video signal (check cable)
    2. Format mismatch (use detect_signal.bat to check)
    3. Device locked (run check_devices.bat)
